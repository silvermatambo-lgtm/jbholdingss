
## Deploy to Vercel
1. Push this folder to a GitHub repository.
2. Import the repo in Vercel.
3. Framework: Vite
4. Build command: `npm run build`
5. Output directory: `dist`
6. Deploy.

`vercel.json` is already included for SPA routing.
